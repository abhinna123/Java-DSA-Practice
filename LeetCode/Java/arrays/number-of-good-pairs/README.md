## Problem

Given an array of integers `nums`, return the number of good pairs. A pair `(i, j)` is called good if `nums[i] == nums[j]` and `i < j`.

The official page contains the complete statement, examples, and constraints: [LeetCode problem](https://leetcode.com/problems/number-of-good-pairs/).

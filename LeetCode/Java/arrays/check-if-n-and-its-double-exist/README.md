## Problem

Given an array `arr` of integers, check if there exist two indices `i` and `j` such that `i != j`, `0 <= i, j < arr.length`, and `arr[i] == 2 * arr[j]`.

The official page contains the complete statement, examples, and constraints: [LeetCode problem](https://leetcode.com/problems/check-if-n-and-its-double-exist/).
